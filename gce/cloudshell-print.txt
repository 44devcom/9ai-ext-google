9ai-ext-google / gce — Cloud Shell

Private repo: do not use cloudshell_git_repo auto-clone (prompts disabled).
Open Cloud Shell, then paste the README one-liner, or from an existing clone:

  ./cloudshell-start.sh

That asks for GitHub credentials if needed, then launches the tutorial.

1) Complete "Select a project" (billing required).
2) Run the bootstrap step, or:
     chmod 755 *.sh && ./cloudshell-bootstrap.sh

That creates 9ai-remote-owner (roles/owner) and ./9ai-remote-owner.key.json
Do not commit the key.
